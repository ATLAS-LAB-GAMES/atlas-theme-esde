# ATLAS discrete custom collections

Revision 10 keeps each supported collection as a normal theme folder at the theme root. Each collection directly includes `../theme.xml`, matching the same loading pattern used by the working `completed` and `now-playing` systems.

Supported collections:

- Digimon Collection
- EA Sports Collection
- Final Fantasy Collection
- Hogwarts Collection
- Jurassic Park Collection
- Mario Collection
- Middle Earth Collection
- Pokemon Collection
- Sonic Collection
- Yu-Gi-Oh Collection
- Zelda Collection

Use **Main Menu → Game collection settings → Group custom collections → Never**.

Create the collection using **Create new custom collection from theme** and select the desired folder. Spaces in these folder names are supported; the folder name, metadata filename, logo filename, title filename and background filename are kept identical and case-sensitive.
